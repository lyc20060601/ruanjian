# 大地图设计说明

关卡地图由 `Assets/JellyWorld/Scripts/JellyLevels.cs` 中的 `MapRows` 定义。每行使用 `#` 表示有效格，`.` 表示缺口；文本从地图顶部向底部书写。

地图缺口不生成底座、果冻或冰层，也不参与交换、匹配和目标统计。每列的果冻只在该列有效格之间下落和补位。
