## 审查方式

建议从第 1 步向后查看，每一步可单独 checkout、编译，再查看下一步。查看单个提交：

```bash
git show --stat be04bc0
git show 27d305e
git diff origin/main...feature/candy-journey-review
```

验收源码提交为 `276e047`；最后一项只补文档、证据和启动入口，不修改已验收的游戏逻辑。最终结果与复现命令集中在 [验收记录](verification/2026-10-25/RESULTS.md)。
