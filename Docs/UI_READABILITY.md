# 界面可读性优化 · 2026-11-01

## 按钮、背景与文案

- 主要按钮使用深紫或深莓红底色与白字；次要按钮保留白底，并增加持续可见的深色描边。
- 降低按钮高光，保留悬停、按压反馈，避免高光把实色按钮冲淡。
- 降低背景山丘的饱和度，为目标、道具和竞速数据增加独立阅读底板。
- 选中的章节和道具使用深色填充；锁定和用完的道具显示不同状态及原因。
- 删除英文装饰、重复口号和泛化鼓励语，保留实际目标、进度、解锁条件与保存规则。
- 为排行榜补充名次、玩家、分数、星星和日期列名。

通过 Unity MCP 执行脚本编译、竞速运行验证和截图；实际检查首页、竞速、关卡和章节页面。使用现有字体、圆角资源和场景素材，未添加外部素材依赖。

## 动态提示栏

- 底部提供持续可读的深色提示栏，按主页、地图、自由模式和竞速显示对应规则。
- 悬停按钮时说明其功能；移开或隐藏按钮后恢复页面提示，避免遗留无关内容。
- 道具选中后持续显示使用和取消方式，临时通知结束后不会丢失当前操作说明。
- 无效交换和受限道具显示醒目原因；锁定关卡悬停或点击时解释解锁条件。
- 临时反馈约 4.5 秒后恢复正常操作说明；暂停及守护者落点选择显示对应快捷键。
- 关卡右侧保留目标与道具状态；自由模式移除没有实际意义的目标进度条，改为显示模式规则。
- 大地图随尺寸增加取景边距，避开顶部信息区与底部提示栏。

提示栏与阅读底板本身不拦截空白区域点击，按钮保留原有点击行为。守护者与靶场使用各自的专用操作栏。
