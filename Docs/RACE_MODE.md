# 计时竞速

首页选择「计时竞速」，再选择 3000、6000 或 10000 分目标。开始后，使用 8×8、五种果冻的标准棋盘，以尽可能少的时间达到目标。竞速无步数限制，不含收集、清冰目标，不使用道具；自然生成的四连、范围和全盘特效保留。

计时从棋盘初始化完成后开始，使用单调实时时钟。暂停、设置窗口和切出应用时停表；需要手动继续。有效交换、无效交换、达标之前的消除与补位动画都计入时间。分数首次达到目标时冻结时间，当前补位结束后展示结果，不追加剩余步数或特效果冻的结算奖励。

结果页支持再次挑战、切换目标和返回主页。三个目标分别保存最快用时，精度为毫秒；未完成的比赛不保存。竞速纪录使用独立的 `JellyWorld.Race.BestMilliseconds.*` PlayerPrefs 键，不改变关卡解锁、星星和原排行榜。重开需要确认，会从零计时。

## 开发与验收

- 计时、目标与纪录：`Assets/JellyWorld/Scripts/JellyRace.cs`。
- 竞速页面、HUD 与流程：`Assets/JellyWorld/Scripts/JellyWorldRace.cs`。
- Unity 菜单「Jelly World → Verify race rules」检查计时边界、暂停、重开、精度、最快纪录和目标隔离。
- Unity 菜单「Jelly World → Verify race and capture UI」执行真实交换与连锁直至达标，并检查暂停、无效交换、道具入口、重开、放弃比赛及模式切换。测试会备份并恢复玩家存档，结束后退出 Play Mode，保持编辑器打开。
- 实际渲染截图和验收报告写入忽略目录 `Captures/RaceUI`，包括 1600×900、1280×720 和 1024×768。通过 MCP 的 `execute_menu_item` 也可以运行这些菜单。
