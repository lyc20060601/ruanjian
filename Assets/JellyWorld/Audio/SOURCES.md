# Downloaded audio

All sounds used by the current game come from downloaded assets; the former runtime-generated sine/noise clips have been removed. Originals are retained under `Downloaded` without audio processing. Runtime playback adjusts gain/pitch and limits simultaneous voices.

| Events | Source files | Source / license |
| --- | --- | --- |
| Ice breaking | `ice-spells/ice.wav` | [Ice spells](https://opengameart.org/content/ice-spells), bart, derived from Stephan / pdsounds; CC0 |
| UI click, hover, swap, pop, invalid move, shooting, shuffle, win/loss | `interface-sounds/click_003.ogg`, `tick_001.ogg`, `switch_002.ogg`, `drop_002.ogg`, `error_002.ogg`, `pluck_002.ogg`, `maximize_003.ogg`, `confirmation_004.ogg`, `error_003.ogg` | [Kenney Interface Sounds](https://kenney.nl/assets/interface-sounds), CC0 |
| Footsteps / heavy impact | `impact-sounds/impactSoft_medium_000.ogg`, `impactSoft_heavy_000.ogg` | [Kenney Impact Sounds](https://kenney.nl/assets/impact-sounds), CC0 |
| Jump / cross beam | `digital-audio/phaseJump1.ogg`, `phaserUp1.ogg` | [Kenney Digital Audio](https://kenney.nl/assets/digital-audio), CC0 |
