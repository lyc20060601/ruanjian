# Project asset sourcing

- User preference: for future changes needing models, materials, sound effects or other media, first search for existing downloadable assets online instead of making new procedural models by default.
- Prefer assets with clear reusable licenses; retain source URLs, author and license alongside imported files.
- Reusing existing project assets and adapting downloaded materials with shaders is acceptable.
- If a required asset source needs login, ask the user to log in. Do not request passwords or bypass authentication.
- Current ice material source: `Assets/JellyWorld/Art/Downloaded/Ice001/SOURCE.md`.

- Sound effects must also be sourced online first. Only synthesize or create sounds if suitable downloadable assets cannot be found. Current sources are recorded under `Assets/JellyWorld/Audio/Downloaded`.
